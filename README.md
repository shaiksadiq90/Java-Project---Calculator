# Java-Project---Calculator
Calculator.java is a command-line calculator that evaluates whole expressions, like 2 + 3 * (4 - 1) / 2. It handles + - * / % ^, parentheses, negative numbers and decimals, and follows normal maths order of operations.  It works by reading the expression left to right, with one small method per operator level.
javac Calculator.java && java Calculator
